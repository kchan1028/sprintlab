# Code of conduct

Be respectful, keep discussion about the work, and do not harass, discriminate against, threaten, or publish private information about another contributor. These expectations apply to issues, pull requests, reviews, and discussions.

## Reporting

The project owner handles conduct concerns. A private conduct-reporting contact has not yet been confirmed; it is an [open decision](roadmap.md#critical-risks-and-decision-points). Do not post private details publicly or use vulnerability reporting for non-security conduct reports. No response-time or third-party enforcement commitment is claimed.
