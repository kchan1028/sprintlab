# SprintLab v1.1.0

Adds the stretch goal: an optional AI story drafter. Everything from [v1.0.0](v1.0.0.md) works as before, and the deployed site looks the same, because the drafter is off there.

**Try it:** clone the repo, run `nvm use && npm install && npm run dev`, and choose **add a demo project**. To try the drafter, copy `.dev.vars.example` to `.dev.vars`, add an Anthropic API key and run `npm run dev:ai` (port 8788).

## New

- **AI story drafter (#17):** on a project page, describe a feature in a few sentences and Claude drafts user stories with priority and acceptance criteria. Edit any draft (same form as work items, including switching it to a bug), discard what you don't want, then add the rest to the backlog in one save. Nothing is stored before you add it.
- Cancel, a 60-second limit, refusals, malformed replies and "nothing to draft" each show a clear message, and your typed request is kept.
- The section is hidden unless the server has a key, so the rest of the app never depends on it.

## How it works

- A Cloudflare Pages Function (`/api/draft-stories`) holds the API key; the browser never sees it. Claude Opus 5.5 at low effort, structured output against a JSON schema, one 50-second attempt, with the API's server-side fallback if the model declines.
- The function checks the model's output and the app checks the function's reply, with the same validation code. Decision record: [ADR-0002](../adr/0002-ai-drafter.md).
- New dependencies: `@anthropic-ai/sdk` (used only by the function) and `wrangler` (development only).
- 248 Vitest tests (40 new); no test calls the real API.

## Known limitations

- **A successful draft with a real API key has not been verified.** Local checks covered the no-key path and the error path against the real API (a placeholder key, rejected as unauthorized, shown as a friendly error); the owner chose to merge #42 without a real-key run.
- **Off in production.** No key is set on the deployed site, because the app has no accounts or rate limiting and an open endpoint would let anyone spend the owner's credits. Turning it on needs abuse protection first ([deployment guide](../deployment.md)).
- The request text and the project's name and description are sent to Anthropic when you draft; the page says so.
- Everything listed for [v1.0.0](v1.0.0.md#known-limitations) still applies: no screen-reader pass, no hosted demo link, one browser's storage, Chromium only, no undo for delete or import.
