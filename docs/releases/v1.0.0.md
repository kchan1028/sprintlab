# SprintLab v1.0.0

The first release: a single-user project and bug tracker that runs entirely in your browser.

**Try it:** clone the repo, run `nvm use && npm install && npm run dev`, and choose **add a demo project**. There's no hosted demo link in this release.

## Features

- Projects with stories and bugs: priority, description, acceptance criteria (#6, #7)
- Five-status board with keyboard-operable status changes (#8)
- Sprints with a required goal, one active sprint per project (#9)
- Sprint planning: assign work, and filter the board by sprint, with the filter kept in the URL (#10)
- Sprint completion with carry-over to the backlog or the next sprint, plus sprint review and retro (#11)
- Delete projects with confirmation; export all data; import a validated backup (#15)
- Demo project based on SprintLab's own backlog (#16)

## Reliability and accessibility

- Failed saves keep changes in memory, with retry, download and a leave-page warning; damaged stored data goes to a recovery screen; a crash fallback replaces a blank page (#12)
- Focus returns after every form, per-page titles, a visible focus ring, and axe checks with no violations on every main screen, including contrast in a browser (#13)
- Every stored record is validated on load; imports also check cross-record integrity (#12, #15)

## Engineering

- React 19, TypeScript 7, Vite 8, React Router 8; data in localStorage behind a repository module
- 208 Vitest tests plus a Playwright smoke test against the production build, all in CI (#3, #14)
- Testing strategy, architecture, ADR, deployment guide, sprint reviews and an AI collaboration log in `docs/`

## Known limitations

- **Not tested with a screen reader.** The planned VoiceOver check ([script](../screen-reader-check.md)) was skipped for this release. Automated axe checks and keyboard-only tests pass, but how the app sounds is unverified.
- **No hosted demo link.** The app deploys to Cloudflare Pages, but the public URL wasn't verified for this release; run it locally.
- Data lives in one browser; use export to back it up
- Tested in Chromium only
- No undo for delete or import (both offer a download first)
